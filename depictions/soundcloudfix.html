SoundCloud iOS 6 Fix

Restores the official SoundCloud 2.7.2 app on jailbroken iOS 6.

SoundCloud retired its v1 API and the password OAuth grant this old client depends on, which broke login, playback, search, feeds and likes/reposts. This tweak rewrites the app's v1 calls to the current v2 endpoints and reshapes the responses so the app can read them.

What it does

  • Playback, search, feeds and likes/reposts rebuilt against the v2 API.
  • Manual credential entry, since the password OAuth grant is gone.
  • Anti-bot session renewed on the device, no cookie pasting.
  • Endpoint table shipped as JSON next to the tweak, editable on-device without reinstalling: soundcloudfix_api_map.json.

Requires

  • Jailbroken iOS with MobileSubstrate.
  • The official SoundCloud app, version 2.7.2.
  • A SoundCloud account — you enter the credentials yourself.

Tested on

iOS 6.1.3 (iPhone 4S). Builds down to iOS 5.0.
