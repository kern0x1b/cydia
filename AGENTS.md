# cydia

## What this is

A static Cydia source: a package index (`Packages`/`.gz`/`.bz2` + `Release`)
served over HTTP, plus the `.deb`s it indexes. Pure distribution point — no
tweak source code lives here, only built `.deb`s, their per-package pages,
and the tooling that regenerates the index. Published at
`https://kern0x1b.github.io/cydia/` via GitHub Pages from this repo's `main`
branch; `.nojekyll` at the root exists so Pages serves `Packages.bz2`,
`Release`, etc. unprocessed.

No device is touched from this repo — `publish.sh` is the only script here
and it only reads/writes local files.

Workspace-wide procedures are skills in `$HOME/Git/projects/ios/.agents/skills/`: `device-session` (claim, run, install, launch, tap on a real device), `canon-install`, `patch-merge`, `worktree-sweep`, `session-handoff`, `band-launch`, `band-supervise`. A session started inside this repository does not list them — read `<name>/SKILL.md` there.

## Layout

| Path | What decides it |
| --- | --- |
| `debs/` | built `.deb`s, checked in — every version, not just the latest |
| `Packages`, `Packages.gz`, `Packages.bz2` | **generated** by `publish.sh` from `debs/` — never hand-edit |
| `Release` | metadata header is hand-written; the `MD5Sum`/`SHA1`/`SHA256` blocks below it are **generated** — never hand-edit |
| `depictions/*.html` | per-package pages Cydia shows instead of plain text; hand-written, one per package that sets `Depiction:` |
| `icons/` | per-package icons served over HTTP, hand-placed; names follow each control file's `Icon:` URL (a package may point at `CydiaIcon.png` instead) |
| `assets/` | full-size source artwork the small icons are scaled from |
| `CydiaIcon.png` | repo icon — must be exactly this name, 64x64, at the root |
| `publish.sh` | the only script here; rebuilds every generated file above |

## Build / publish

Reindex what's already in `debs/`:
```
./publish.sh
```

Copy a newly-built `.deb` in and reindex (`build.sh` repos write `dist/`,
charon/xmake repos write `build/`):
```
./publish.sh <tweak-repo>/dist/*.deb
```

`publish.sh` runs `dpkg-scanpackages -m` (the `-m` keeps every version in the
index — without it only the newest survives and older debs in `debs/` become
unreachable), writes `Packages.gz`/`.bz2` alongside the plain index, and
rewrites the checksum blocks in `Release`. It requires `dpkg-scanpackages`,
`gzip`, `bzip2`, and `md5`/`md5sum` + `shasum` on `PATH`.

For the full publish procedure — building the deb in its own repo, updating
the README table and a depiction page, committing — see the
`publish-tweak` skill (`.agents/skills/publish-tweak/SKILL.md`).

## Conventions

- Commit subjects are plain imperative statements, no type prefix:
  `Publish Kindle Whispersync Fix 1.0.2`, `Give the Kindle package its own
  artwork`, `Serve the depiction stylesheet`.
- Never hand-edit `Packages` or the checksum block in `Release` — both are
  fully regenerated by `publish.sh` and any manual edit is lost on the next
  publish.
- Keep every version of a `.deb` in `debs/`; do not delete old versions when
  publishing a new one.

## Traps

- Old Cydia asks for `Packages.bz2` first, then `.gz`, then plain — all three
  must be published, not just one.
- `dpkg-scanpackages` without `-m` drops every version but the newest from
  the index, silently orphaning older `.deb`s already in `debs/`.
